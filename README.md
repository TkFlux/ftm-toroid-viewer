# FTM Compact Toroid Viewer

Educational interactive sketch of Field-Reversed Configuration (FRC) / compact-toroid geometry with a co-rotating hammer.

## Open the viewer

- **GitHub Pages** (if enabled): https://tkflux.github.io/ftm-toroid-viewer/
- Or open `index.html` directly in a modern browser.

## Controls

- **Drag** to orbit the camera
- **Scroll / pinch** to zoom
- **Sliders** in the left panel adjust geometry, spin, and hammer parameters

This is a conceptual visualization for learning, not a physics simulation or engineering design tool.
